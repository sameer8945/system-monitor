## Installation (Linux)

```bash
git clone https://github.com/sameer8945/system-monitor.git
cd system-monitor

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
python app.py
```

## Installation (Windows)

```powershell
git clone https://github.com/sameer8945/system-monitor.git
cd system-monitor

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt
python app.py
```
